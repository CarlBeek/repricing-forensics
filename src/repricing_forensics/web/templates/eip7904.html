1. Headline Numbers

"Wallet-fixable" means simple calls where the sender just needs a higher gas estimate — wallets auto-correct this via eth_estimateGas. "Contract-broken" means the failure is structural and requires code changes. The wallet-fixable bucket includes a "deep call chain" sub-bucket: txs whose entire call chain forwards gas via the EIP-150 63/64 rule, so a higher wallet gas limit propagates all the way down. These look like contract failures in a naïve view but resolve themselves once the wallet retries with more gas.

2. Transaction Breakdown

Every re-executed transaction falls into one of these buckets. "Trace-divergent only" means the EVM trace differed from baseline at some intermediate step but the final outcome — gas used, event logs, status — all match, so no observable impact. "Gas-only change" means it succeeded under both schedules but used more gas under EIP-7904. "Event logs changed" means internal outcomes shifted enough to emit different events. "Broken" means a previously-successful transaction now reverts.
